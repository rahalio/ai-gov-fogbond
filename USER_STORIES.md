# Fogbond — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Tactical commander / battle captain

- As a platoon commander, I want to see which edge agents around me hold current bonds for noncombatant classification, so that I know what I can trust when we lose reachback.
- As a battle captain, I want a bond to fail closed when restore-to-function evidence expires mid-mission, so that I am not silently relying on a degraded agent.
- As a commander, I want an explicit withhold recommendation with evidence when sensors flag noncombatants, so that speed does not erase accountability.

### Edge autonomy / cyber resilience engineer

- As an edge engineer, I want to enrol an agent family with its diversity tags and quiet-comms modes, so that the bond battery tests the configuration we will actually field.
- As a resilience analyst, I want scripted jam and deception injects to be part of renewal, so that we measure restore behaviour rather than lab accuracy alone.
- As an engineer, I want intermittent sync to record inferred versus received state, so that forty-five minutes of disconnect does not produce a silent false common operating picture.

### Exercise director / T&E evaluator

- As an exercise director, I want live cyber and EW play to run to completion with bond outcomes scored, so that training produces corrections instead of stopping the game.
- As a T&E evaluator, I want lab bonds and contested-exercise bonds kept distinct, so that acquisition cannot treat a sandbox score as operational assurance.

### Ethics / targeting advisor

- As a targeting advisor, I want human corrective authority named on every force-relevant classification path, so that “autonomy” never means unsupervised lethal discretion.
- As an ethics officer, I want adversarial bias and deception failures itemised, so that known brittleness is not buried in aggregate accuracy.
- As a maintainer, I want quiet-comms failure modes on the bond checklist, so that loud reachback links are not assumed when the bond was issued for contested silence.

### Programme / platform administrator

- As a programme manager, I want monoculture risk and bond coverage reported by kill chain, so that I can fund diversity before a single malware event.
- As a platform administrator, I want immediate revocation with command-visible audit when quarantine thresholds trip, so that assurance is a living control rather than a certificate on a shelf.
- As a coalition liaison, I want controlled-release evidence packs, so that partners can verify bonds without receiving raw tactical feeds.
